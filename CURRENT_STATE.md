- ✅ Android (5.0+)
- ⚠️ Web (только для разработки, VPN не работает)

## 📝 Примечания

1. **VPN на Web**: flutter_vless не работает в браузере, только на мобильных платформах
2. **Тестовые серверы**: Текущие серверы - это заглушки, нужно подключить реальный backend
3. **Без авторизации**: Приложение работает без регистрации/входа
4. **Реклама**: SDK рекламы пока не интегрирован
